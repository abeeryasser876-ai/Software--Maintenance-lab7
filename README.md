## Project Purpose 
The main purpose of this project is to practically apply the **Git Feature Branch Workflow** and secure connection as learned in the Software Maintenance Lab. We aim to demonstrate how to manage a simple software project using version control best practices.

## Project Goal 
To create a simple web page that serves as a practical example of how a feature can be developed in an isolated branch, reviewed, and then successfully merged into the main branch without affecting the stability of the main codebase.

## Project Features 
1. **Simple Web Interface:** A basic HTML page (`index.html`) that displays a welcome message for the project.
2. **Version Control Implementation:** 
   - Utilization of feature branches for safe development.
   - Proper commit messages documenting the changes.
3. **Documentation:** A comprehensive `README.md` file explaining the workflow and project details.
4. **Secure Connection:** Established a secure connection between the local development environment and the GitHub repository.

## Workflow Steps Followed
1. Created a new branch.
2. Added new files and changes.
3. Committed changes with a clear message.
4. Pushed the branch to GitHub.
5. Created a Pull Request and Merged it into the `main` branch.
